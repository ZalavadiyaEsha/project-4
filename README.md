# Project 4 - C Pattern Printing Programs

A collection of C language programs that generate various geometric and number patterns using nested loops.

## 📁 Included Programs

* `alphabetipattern.c` - Pattern using alphabetical characters
* `customnumeric.c` - Custom numeric number patterns
* `floyds.c` - Floyd's Triangle pattern
* `halftriangle.c` - Standard right-angled half triangle
* `invertedlefthalgtriangle.c` - Inverted left half triangle pattern
* `pyramid.c` - Full star/number pyramid pattern
* `righthalftriangle.c` - Right half triangle pattern

## 🛠️ How to Compile and Run

To run any of these pattern programs locally using GCC:

```bash
gcc pyramid.c -o pyramid
./pyramid
